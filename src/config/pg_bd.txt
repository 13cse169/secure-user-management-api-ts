1. Connect PostgreSQL

    Connect using the command that worked for you:
    & "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -h localhost -p 2124

    Replace 18 with your installed version if necessary.

    Enter your password. 

    You should see a prompt similar to: postgres=#

2. Create the project database
    
    CREATE DATABASE secure_user_management;

3. Connect to your new database

    \c secure_user_management
    
    You should see a prompt similar to: secure_user_management=#

4. Create the users table
    CREATE TABLE users (
        id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
        name VARCHAR(100) NOT NULL,
        email VARCHAR(255) NOT NULL,
        password_hash TEXT NOT NULL,
        is_email_verified BOOLEAN NOT NULL DEFAULT FALSE,
        is_active BOOLEAN NOT NULL DEFAULT TRUE,
        created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
        updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),

        CONSTRAINT users_name_not_empty
            CHECK (LENGTH(TRIM(name)) > 0),

        CONSTRAINT users_email_not_empty
            CHECK (LENGTH(TRIM(email)) > 0)
    );

    CREATE UNIQUE INDEX users_email_unique_idx
    ON users (LOWER(email));

    The unique index on LOWER(email) prevents duplicate emails even when their letter casing differs. For example, User@gmail.com and user@gmail.com cannot both be registered.

    Security note: We will hash passwords before saving them. We will never store plain-text passwords.

5. Verify the table

    \d users

    SELECT * FROM users;
